Overview

Bake and reshape ipv4 text streams with deterministic transforms. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/bakeipv4.git
cd bakeipv4
node src/cli.js --help
node --test
